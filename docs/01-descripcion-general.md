# Descripción general del proyecto

## Nombre del proyecto

**Un Rincón Maravilloso de PT**

## Descripción

Un Rincón Maravilloso de PT es una aplicación web orientada a la venta y distribución de recursos educativos digitales relacionados con la Pedagogía Terapéutica.

La aplicación permite a los usuarios consultar recursos, guardar favoritos, comprar materiales, acceder a sus descargas, enviar reseñas, abrir consultas de soporte y enviar sugerencias.

Además, incorpora un panel de administración desde el que se pueden gestionar productos, recursos gratuitos, usuarios, tickets de soporte, sugerencias, mensajes de contacto y reportes.

## Objetivos

Los principales objetivos del proyecto son:

- Crear una tienda online de recursos educativos digitales.
- Diferenciar entre usuario cliente y administrador.
- Gestionar recursos de pago y gratuitos.
- Permitir compras y descargas de materiales.
- Incorporar soporte y comunicación con los usuarios.
- Aplicar validaciones en cliente y servidor.
- Utilizar tecnologías vistas durante el ciclo formativo.
- Documentar el proyecto y prepararlo para despliegue.
