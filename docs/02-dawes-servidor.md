# DAWES - Desarrollo Web en Entorno Servidor

## Lenguaje PHP

El proyecto está desarrollado con PHP como lenguaje principal de servidor.

PHP se utiliza para:

- Procesar formularios.
- Gestionar sesiones.
- Controlar usuarios y roles.
- Consultar la base de datos.
- Renderizar vistas.
- Gestionar productos, compras, descargas, soporte y administración.

## Base de datos

La aplicación utiliza una base de datos MySQL/MariaDB.

La conexión se realiza mediante PDO, lo que permite utilizar consultas preparadas y mejorar la seguridad frente a inyección SQL.
